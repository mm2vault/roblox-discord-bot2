Kurulum

  1. OpenRouter hesabından bir API anahtarı oluştur.
  2. Netlify → Site configuration → Environment variables bölümüne gir.
  3. OPENROUTER_API_KEY adında değişken oluşturup anahtarı değer olarak ekle.
  4. Siteyi yeniden deploy et ve buraya dön.
