# AI Hub

A multi-model AI assistant web app powered by OpenRouter and Netlify Functions.

## Features
- Chat with multiple AI models through one API provider.
- Load the available model list dynamically.
- Keep API keys server-side with Netlify environment variables.
- Responsive dark interface.

## Setup
1. Install dependencies with `npm install`.
2. Set `OPENROUTER_API_KEY` in your Netlify environment variables.
3. Deploy the site on Netlify.
4. Open the app and choose an available model.

Never put API keys in frontend files or commit `.env` files.
